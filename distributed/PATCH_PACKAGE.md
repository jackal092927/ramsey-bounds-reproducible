# Launch mapping

Prepared on 2026-10-12 from the locally validated certificate package. The
original candidate remains frozen in the observatory. This deployment changes
community documentation and copies the active CI/PR template to the repository
root; validator, schema, test and baseline certificate bytes are unchanged.

`SOURCE_MANIFEST.json` binds this launch package. `VALIDATION_RECEIPT.json` is the
original local receipt at its original timestamp, not a GitHub CI receipt. Live
Actions and the launch commit are tracked separately. No numerical improvement
is introduced by this deployment.
