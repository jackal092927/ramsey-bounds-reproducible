\section{Introduction}\label{sec:introduction}

Ramsey's theorem guarantees that every sufficiently large graph contains a
large clique or independent set.  Its classical constructive proof
\cite{ErdosSzekeres1935} repeatedly chooses a pivot and restricts the
candidate set to one of its two colour neighbourhoods.  Starting from
$M=4^{K-1}$ vertices, truncating each retained neighbourhood to half its
current size gives an $O(M)$-query algorithm.

The central observation of this paper is that the candidate sets need not be
materialized.  After $i$ rounds, membership in the current set is determined
by the $i$ adjacency constraints imposed by the previous pivots.  These short
predicates allow quantum search to access the same recursion at substantially
smaller query cost.  The threshold $4^{K-1}$ matches this recursive
construction.

We work in the promised valid-graph adjacency-oracle model.  One coherent
query returns the colour of a requested unordered vertex pair, and the output
is a set of vertices inducing one colour.  Our main result is the following.

\begin{theorem}[Implicit-majority quantum Ramsey search]
\label{thm:main}
Let $K\ge2$, $N\ge4^{K-1}$, and $0<\eta<1/2$.  Given coherent edge-oracle
access to a simple undirected graph on $N$ vertices, there is a quantum
algorithm which, with probability at least $1-\eta$, outputs a $K$-clique or
a $K$-vertex independent set using
\[
 O\!\left(2^K K\log\frac K\eta\right)
\]
edge queries in the worst case.  The algorithm verifies every returned
witness and may output $\bot$ on the exceptional event.
\end{theorem}

\begin{corollary}\label{cor:succinct}
For a promised simple graph on $N=2^n$ vertices, one can find a clique or
independent set of order $\lfloor n/2\rfloor+1$ using
\[
 O\!\left(
 \sqrt N\log N\log\frac{\log N}{\eta}
 \right)
\]
edge queries.
\end{corollary}

\paragraph{Two implicit-set recursions.}
The first algorithm avoids majority estimation altogether.  At each round it
samples a uniform candidate and follows the colour of its edge to the current
pivot.  The selected colour class is therefore chosen with probability
proportional to its size.  A survival lemma shows that this size-biased
recursion completes with probability greater than $1/2$ from $4^{K-1}$
vertices, yielding an
$O(2^K K^2\log K\log(1/\eta))$-query algorithm.

The sharper algorithm estimates a majority colour at each pivot.  Sampling a
deep candidate set is exponentially more expensive than sampling an early
one, so a uniform accuracy requirement wastes queries at the deepest levels.
We instead allocate a fixed total error budget across the recursion: early
majorities receive higher accuracy, while later majorities receive larger
allowable error.  A dyadic schedule balances these costs and gives
\cref{thm:main}.  The size-biased argument also extends to every fixed number
of edge colours; see \cref{cor:multicolour}.

\paragraph{Contributions.}
The paper makes three main contributions.
\begin{itemize}
\item It gives a worst-case
$O(2^K K\log(K/\eta))$ quantum-query algorithm for constructive diagonal
Ramsey search, or $\widetilde O(\sqrt N)$ queries at the succinct Ramsey
scale.
\item It develops two methods for navigating the implicit recursion: a
size-biased rule with a direct survival analysis, and a scale-aware majority
estimator whose accuracy budget is matched to the cost of each level.
\item It extends the size-biased method to a fixed number of colours and proves
a randomized classical lower bound of
$\Omega(M^{1-1/\sqrt2})$ for $M=4^{K-1}$.
\end{itemize}

\paragraph{A reported lower-bound discrepancy.}
At the default $N=2^n$, $K=n/2$ parameters,
\cite[Section III, p.~415]{JainLiRobereXun2024} reports an
$N^{1-o(1)}$ quantum-query lower bound for the same Ramsey relation.  This
creates an apparent discrepancy with \cref{cor:succinct}.
Section~\ref{sec:prior-art} aligns
the two formulations and shows that direct substitution into the cited
ingredients yields an exponent at most $1/24$, rather than $1-o(1)$.

The rest of the paper defines the oracle model and capped sampler, presents
the two recursions, proves their correctness and query bounds, derives the
randomized classical lower bound, and compares the result with prior work.
