\section{Independent verification protocol}\label{app:protocol}

This appendix states a reviewer-oriented protocol.  It is intentionally more
specific than the convenience wrapper in the repository.

\subsection{Seed verification}

Parse the \(100\times100\) matrix, reject any non-binary, asymmetric, or
non-zero-diagonal input, and verify its SHA-256.  Count undirected edges by the
strict upper triangle.  Enumerate every vertex triple and record all
triangles.  Run the exact independent-set verifier at target \(18\).  Repeat
the structural checks for the \(99\)-vertex principal submatrix and compare it
byte-for-byte with its separately stored certificate.  A successful outcome
must report \(827\) edges and exactly the triangle \(\{97,98,99\}\) for \(H\),
and \(809\) edges, no triangle, and no independent \(18\)-set for \(G_0\).

\subsection{Formula reconstruction}

For each exact-six branch \(i\):
\begin{enumerate}[label=\arabic*.]
\item Assign primary identifiers \(1,\ldots,4950\) to pairs in lexicographic
order.
\item Generate the \(161700\) triangle clauses in lexicographic triple order
and compare them to the DIMACS prefix.
\item Form the \(826\) residual deletion literals in stored seed-edge order.
Regenerate the PySAT sequential equality counter at bound five.  Compare all
\(16420\) clauses and the final variable identifier \(13160\).
\item Compare the fixed negative unit for \(f_i\).
\item For each remaining clause, require \(153\) distinct, positive primary
literals.  Invert the pair map, recover exactly \(18\) vertices, and verify
that the clause is the full \(\binom{18}{2}\) pair family of those vertices.
\item Compare the recovered ordered masks with the frozen cut bank and check
that no unparsed clause remains.
\end{enumerate}

The analogous budget-five reconstruction replaces equality at five by an
at-most-four counter.  It has \(8238\) total variables and \(7394\) counter
clauses in each branch.  The three hitting-bank sizes are \(287\), \(15872\),
and \(8704\).

\subsection{DRAT replay}

Build \texttt{drat-trim} from source commit
\sha{2e3b2dc0ecf938addbd779d42877b6ed69d9a985}.  Verify that the source tree is
clean.  The repository helper
\begin{verbatim}
bash scripts/build_drat_trim.sh /absolute/new/checker-directory
\end{verbatim}
performs this source checkout and records the resulting binary hash.  A fresh
platform build need not reproduce the historical executable hash.  For each
of the twelve compressed assets in
\cref{tab:budget5-artifacts,tab:budget6-artifacts}, check compressed byte count
and SHA-256, test gzip integrity, and decompress into a new temporary
directory.  Then invoke
\begingroup\small
\begin{verbatim}
/path/to/drat-trim formula.cnf proof.drat
\end{verbatim}
\endgroup
and require both exit status zero and an exact output line
\texttt{s VERIFIED}.  The checker may print timing diagnostics after that
status line.
Delete the temporary raw files only after recording the uncompressed hashes.

For the complete package, the repository offers integrated semantic and proof
replay:
\begingroup\scriptsize
\begin{verbatim}
.venv/bin/python reproduce.py finite-heavy \
  --artifact-dir /path/to/release-assets \
  --drat-trim /path/to/drat-trim
\end{verbatim}
\endgroup
Time limits may need to be increased on slower hardware.  A timeout is
\textsc{unknown}, never a failed or successful proof.

\subsection{Logical audit checklist}

A reviewer can check the mathematical implication independently of the code:
\begin{enumerate}[label=\arabic*.]
\item the three \(f_i\) are precisely the edges of a seed triangle;
\item every triangle-free final graph omits at least one \(f_i\);
\item original nonedges are primary variables but not deletion literals;
\item every installed \(C_S\) is entailed by \(\alpha(F)<18\);
\item omitting uninstalled \(C_S\) clauses makes the CNF weaker, so an UNSAT
result remains sufficient;
\item the budget-five refutations force any putative budget-six candidate to
have exactly six deletions;
\item after choosing one absent \(f_i\), exactly five residual deletion
literals are true; and
\item checked UNSAT of all three exact-six branches contradicts the model
provided by any candidate graph.
\end{enumerate}
