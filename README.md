# Reproducible Ramsey bounds

This repository is the publication and reproduction package for three
separate outputs:

| output | principal statement | source |
|---|---|---|
| upper-bound paper | $R(k,k)\le(3.780685290)^{k+o(k)}$ within the pinned computer-assisted trust boundary | [`papers/upper/main.tex`](papers/upper/main.tex) |
| lower-bound paper | a source-relative fixed-large-$C$ addition $\widehat H_*(C)=(1+o(1))/(64\log C)$ | [`papers/lower/main.tex`](papers/lower/main.tex) |
| finite computational report | the named 100-vertex $R(3,18)$ near miss has deletion repair radius at least seven under free additions | [`papers/finite/main.tex`](papers/finite/main.tex) |

The finite report does **not** prove $R(3,18)\ge101$, and its exact-seven
repair question remains open. The lower-bound result is source-relative and
does not claim a common-normalization improvement over every published final
constant. The upper result is asymptotic and does not provide an effective
finite-$k$ threshold or a priority/world-best claim. The authoritative claim
boundary is summarized in [`STATUS.md`](STATUS.md).

## Clean reproduction

Reference environment: Python 3.11.15 with dependencies locked in
[`uv.lock`](uv.lock). From a clean clone:

```bash
bash scripts/bootstrap.sh
.venv/bin/python reproduce.py quick
make papers
```

`quick` replays the four current upper checkers, the current lower checker,
all 28 finite-route unit tests, and five direct graph-certificate checks. The
long interval chain is deliberately separated:

```bash
.venv/bin/python reproduce.py full
```

Large CNF/DRAT files are GitHub Release assets rather than ordinary Git
objects. Download all files named in
[`artifacts/MANIFEST.tsv`](artifacts/MANIFEST.tsv), then run:

```bash
bash scripts/download_release_artifacts.sh
.venv/bin/python reproduce.py finite-heavy \
  --artifact-dir artifacts/downloads \
  --drat-trim /absolute/path/to/drat-trim
```

The proof checker is pinned to source commit
`2e3b2dc0ecf938addbd779d42877b6ed69d9a985`; compiled-binary hashes in the
historical records are provenance, not a portability requirement. Versioned
arXiv sources can be fetched and hash-checked, without vendoring them, with
`scripts/fetch_external_sources.py`.

PDFs generated by `make papers` are the submission-oriented manuscripts.
The underlying `routes/` files retain the full frozen search, certificate,
and referee history.

## Lower-bound route

The HMS optimized-appendix comparator has now been rebuilt on the red side.
For every sufficiently large fixed $C$, the proof package gives the theorem

\[
\liminf_{\ell\to\infty}\frac1\ell
\log R(\ell,\lfloor C\ell\rfloor)
\ge -\frac12\log p_C+\frac1{20}+\frac{c_R(C)}{4D^2},
\]

where $c_R(C)>0$ is defined by compact-window inverse-Mills and conditional-
variance extrema.  The genuinely new same-ledger gain is

\[
\frac{c_R(C)}{4D^2}=\frac{1+o(1)}{32\log C}.
\]

The $1/20$ checkpoint itself includes unused slack already present in HMS's
public probability lemma; it is not all attributable to the new argument.  A
common-history Hölder/CGF deficit is inserted before HMS coarsening, propagated
through the exact appendix induction, and preserved by a quantified
perfect-sequence extraction.  The unchanged blue estimate has ample asymptotic
slack.  An independent source-level referee replay found no fatal gap; its one
formal endpoint comment was repaired in the proof package. The HMS source
leaves relevant error constants inside `O/o` notation, so the proof gives the
existence of a sufficiently large threshold but no certified numerical $C_0$.
The result remains a **local proof-package theorem pending external human
review**, not a published bound. See
[`routes/lower/HMS_APPENDIX_BRIDGE.md`](routes/lower/HMS_APPENDIX_BRIDGE.md) and
[`routes/lower/INDEPENDENT_APPENDIX_REFEREE.md`](routes/lower/INDEPENDENT_APPENDIX_REFEREE.md).
An additional adversarial replay, which specifically targeted the subtraction,
reverse-induction, extraction, and rate-conversion steps, also found no fatal
gap; see
[`routes/lower/ADVERSARIAL_APPENDIX_REVIEW.md`](routes/lower/ADVERSARIAL_APPENDIX_REVIEW.md).

A source-faithful parameter optimization now strictly improves the explicit
positive term for every sufficiently large fixed $C$.  It keeps the exact
upper-truncated Gaussian CGF, uses the largest step-dependent legal Holder
exponent, and approaches the limiting cutoff window from above.  Writing the
new term as $G_*(C)$, the package proves

\[
G_*(C)>\frac{c_R(C)}{4D^2},\qquad
G_*(C)=\frac{1+o(1)}{32\log C}.
\]

The strict inequality already holds with the old window and old Holder pair;
the other optimizations further improve the finite-$C$ term.  Within the
precisely delimited class of deterministic, history-uniform, per-step
centered-moment deficits that are then added in the same reverse induction,
the coefficient $1/32$ is sharp.  This does not exclude history-dependent
couplings or changes to the mean, dimension, blue construction, or graph
model.  An independent source-level referee accepted both the strict fixed-
$C$ theorem and the deliberately narrow method-cap statement.  See
[`routes/lower/LOWER_HMS_PARAMETER_OPTIMIZATION.md`](routes/lower/LOWER_HMS_PARAMETER_OPTIMIZATION.md)
and
[`routes/lower/INDEPENDENT_HMS_PARAMETER_OPTIMIZATION_REFEREE.md`](routes/lower/INDEPENDENT_HMS_PARAMETER_OPTIMIZATION_REFEREE.md).

A controlled-residual optimization now supersedes the exact-merge weighted
mean ledger, relative to the same pinned source snapshots and frozen bridge.
For every fixed sufficiently large $C$, it preserves the preceding $G_*(C)$
term and proves

\[
\liminf_{\ell\to\infty}\frac1\ell
\log R(\ell,\lfloor C\ell\rfloor)
\ge -\frac12\log p_C+\frac{B_R(C)}2+G_*(C)+\widehat H_*(C),
\]

and hence the public coarsening with $B_R(C)/2$ replaced by $1/20$, where

\[
\widehat H_*(C)=\frac{1+o(1)}{64\log C}>0.
\]

The proof retains the full-box strong-concavity term and pays a deterministic
boundary-gradient residual by square completion.  Exact multiplicities then
combine the old feedback mass and the residual gain without double counting
$G_*(C)$.  The predecessor exact-merge term
$H_*(C)=(1+o(1))/(96\log C)$ remains valid but is superseded.  The narrow
$1/64$ method cap applies only to the explicitly stated scalar class: the same
weighted-pair recursion, nonnegative deterministic increments fixed before
column sampling, uniform full-box scalar square completion, and the same
three-factor Holder/CGF comparison.  It is not a cap on adaptive or
higher-order potentials.
