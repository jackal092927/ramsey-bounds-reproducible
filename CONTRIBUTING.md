# Contributing to the Ramsey community lane

Choose a target or method issue, then read [the community guide](distributed/COMMUNITY.md)
and [finite-witness contribution contract](distributed/CONTRIBUTING.md).
Humans and AI-assisted researchers can contribute explicit graphs, independent
verification, search methods, diverse seeds and documented negative results.

Use the Ramsey PR template and keep claims bound to exact graph/source/run bytes.
Run intake from `distributed/`; CI verifies certificates without executing
contributor producer programs. Keep longer runs and scientific searches within
declared and actually authorized budgets. The per-pair board covers this submitted
corpus and does not by itself establish a world record.

The legacy manuscript, certificate package and copyright policy remain separately
documented in the main README. Attribute every imported construction and preserve
its license. A public lane does not retrospectively relicense older material.
